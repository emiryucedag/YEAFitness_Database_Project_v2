# YEA Fitness Database Management System

The **YEA Fitness Database Management System** is a software project designed to manage the core operations of a fitness center. The system provides tools for managing users, trainers, exercise programs, and sports facilities in an organized and efficient way.

The backend of the system is built using **MySQL**, while the application interface was initially developed with **Java**. In the updated **Version 2**, a modern **React-based user interface** was added to improve usability and enhance the overall user experience.

---

## Features

### User Management
- Users can register and manage their profiles.
- Access available services within the system.

### Trainer Management
- Trainers can be assigned to users.
- Trainers can create and manage customized exercise programs.

### Exercise Program Management
- Create and organize personalized workout programs.
- Track and manage exercise routines.

### Sports Facility Reservations
- Users can view available sports facilities.
- Book and manage reservations for sports fields.

This project demonstrates the implementation of a **database-driven management system** for fitness centers, focusing on efficient data organization, user interaction, and facility reservation management.
